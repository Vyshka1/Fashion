# Гардероб — конструктор образов

Личное приложение в духе Acloset: складываете сюда вещи (в том числе те,
которые только собираетесь купить), а оно само собирает из них образы —
с учётом цвета, сезона и стиля.

Работает прямо в браузере телефона, без регистрации и без сервера.
Все фото и вещи хранятся только на вашем устройстве.

## Как запустить

**На телефоне (рекомендуется).** Включите GitHub Pages для этого репозитория:
`Settings → Pages → Source: Deploy from a branch → ветка с этим кодом, папка / (root)`.
Через минуту приложение открывается по адресу вида
`https://<ваш-логин>.github.io/fashion/`.

Дальше в Safari: **Поделиться → На экран «Домой»**. Приложение появится иконкой
рядом с остальными и будет открываться на весь экран, в том числе без интернета.

**На компьютере.** Из папки проекта:

```bash
python3 -m http.server 8000
```

и открыть `http://localhost:8000`. Просто двойным щелчком по `index.html`
открывать не стоит: браузеры запрещают локальным файлам пользоваться
хранилищем, и вещи не сохранятся.

## Как пользоваться

1. **Добавить вещь** — кнопка «+». Можно выбрать сразу несколько скриншотов
   из галереи (а на компьютере — перетащить файлы или вставить из буфера).
2. **Кадрировать** — оставьте в рамке только саму вещь. От этого зависит,
   насколько точно определится цвет.
3. **Заполнить карточку** — категория, цвет (предлагается 5 оттенков с фото,
   любой можно поменять вручную), сезон, стиль, цена и ссылка на товар.
   Статус «Хочу купить» или «Уже есть».
4. **Образы** — приложение собирает варианты само. Фильтры: повод, сезон,
   участие вещей из списка покупок. Кнопка ↻ пересобирает подборку.
5. **Луки** — понравившиеся образы сохраняются сюда.
6. **Собрать вокруг вещи** — в «Гардеробе» нажмите ✓ в правом верхнем углу,
   отметьте вещи и нажмите «Собрать образ»: они войдут в каждый вариант.
   Удобно, когда хочется понять, с чем носить конкретную покупку.

## Как подбираются образы

Каждое сочетание оценивается по 100-балльной шкале из четырёх частей:

| Что учитывается | Вес | Как считается |
|---|---|---|
| Цвет | 42% | попарная сочетаемость по цветовому кругу; нейтральные (белый, чёрный, серый, бежевый, джинса) дружат со всем, земляные тона — между собой; худшая пара в образе весит особенно много, а больше двух активных цветов снижает оценку |
| Стиль | 26% | совпадение с поводом и разброс по формальности: кроссовки к вечернему платью получают штраф |
| Сезон | 18% | общий сезон у всех вещей |
| Полнота | 14% | есть ли обувь, сумка, верхняя одежда |

Дополнительно начисляются баллы за приёмы, которые работают в жизни:
обувь и сумка в одном тоне, перекличка верхней одежды с аксессуаром,
один акцентный цвет на спокойной базе. Каждая карточка показывает,
почему образ собрался именно так.

Верхняя одежда предлагается по сезону (зимой — всегда, летом — никогда),
на одну связку «верх + низ» показывается не больше двух вариантов, а одна
вещь не попадает больше чем в три образа подряд — чтобы подборка не
выглядела как один и тот же лук с перестановками.

## Данные

Всё лежит в IndexedDB вашего браузера — ничего не уходит в сеть.
Отсюда следствия:

- Данные привязаны к браузеру и устройству. Очистка данных сайта или
  удаление приложения с экрана «Домой» их сотрёт.
- В «Настройках» есть **Экспорт** — один JSON-файл со всеми вещами и фото.
  Им же переносятся данные на другое устройство (**Импорт**).

Фото сжимаются при добавлении: сама вещь до 1100 px по длинной стороне,
превью — 320 px. Одна вещь занимает около 100–150 КБ.

## Структура

```
index.html            экраны и разметка
css/styles.css        оформление
js/color.js           определение цвета вещи по фото, названия оттенков, сочетаемость
js/taxonomy.js        категории, сезоны, стили, поводы
js/store.js           хранилище (IndexedDB, откат на localStorage)
js/cropper.js         кадрирование фото
js/outfits.js         перебор и оценка образов
js/ui.js              отрисовка экранов
js/app.js             состояние и события
sw.js                 офлайн-кэш
tests/engine.test.js  проверки логики
```

## Тесты

```bash
node tests/engine.test.js
```

Проверяют названия цветов, правила сочетаемости и сборку образов:
что в образе всегда есть база и по одной вещи из категории, что работают
фильтры по сезону и поводу, закрепление вещей и повторяемость подборки.
